# Ghostty (`.config/ghostty/`)

- The config file is `config.ghostty` (Ghostty's auto-created name), not `config`.
- Only set options that differ from the defaults; don't paste `ghostty +show-config --default`. List options with `ghostty +show-config --default --docs` and keybinds with `ghostty +list-keybinds --default`.
- Colors (background, foreground, cursor, selection) come from the wallpaper: `config-file` includes `~/.cache/wallpaper-colors/ghostty`, generated by matugen (`matugen.md`). Colors set in `config.ghostty` are overridden by it.
- Reload with Ctrl+Shift+, ; some options only apply to new windows.
- Hyprland grabs keybinds before Ghostty, so check `.config/hypr/modules/keybinds.lua` before binding `Super` combos.
