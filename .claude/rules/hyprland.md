# Hyprland (`.config/hypr/`)

Hyprland (written against 0.57) using the **Lua config**.

- `hyprland.lua` only `require`s `modules/*.lua`. Put new settings in the matching module (`keybinds.lua`, `look.lua`, `input.lua`, …).
- `modules/quickshell.lua` starts the bar at login with `qs -n` and binds SUPER+R to `qs ipc call workspaces rename`.
- Border colors (`general.col.*`) come from the wallpaper: `modules/look.lua` loads `~/.cache/wallpaper-colors/hyprland.lua`, generated by matugen (`matugen.md`). The values in `look.lua` are only the fallback.
- Validate changes with `hyprctl reload && hyprctl configerrors`.

## Dispatch syntax

Dispatchers are Lua expressions, wrapped by Hyprland as `return hl.dispatch(<arg>)`, e.g. `hl.dsp.focus({ workspace = 2 })`. Classic strings like `"workspace 2"` fail with "')' expected". Test a command with `hyprctl dispatch '<expr>'` first. This applies to Quickshell's `Hyprland.dispatch(...)` too.
