# Wallpapers

Images here (`.jpg`, `.jpeg`, `.png`, `.webp`) are shown by Quickshell, sorted by name.
With none, a Tokyo Night gradient is drawn instead.

- Next / previous: SUPER+SHIFT+W, or `qs ipc call wallpaper next` / `prev`
- Pick one: `qs ipc call wallpaper set forest.jpg` (a file here, or an absolute path)
- Current: `qs ipc call wallpaper get`

The choice is remembered across restarts. Images here are git-ignored, so each machine keeps its own set.
